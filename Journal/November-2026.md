Dove into python dictionaries a little more, from what I understood, dicts are key-value pairs like a list.

For example,

```
dict = {"name": "Hemang", "age": 20}dict["name"]  # returns the value, "Hemang"dict["height"] = 180  # adds to dictdict.get("name", 0)  # lets us check if key is present
```

- `.values()` gives values
    
- `.keys()` gives keys
    
- `.items()` gives both
